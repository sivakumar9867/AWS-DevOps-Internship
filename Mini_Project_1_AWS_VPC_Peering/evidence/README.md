# Evidence – AWS VPC Peering

This folder stores the final project report and supporting implementation evidence.

## Evidence Report

The consolidated project report is intended to be stored here as:

`AWS_VPC_Peering_Project_Report.pdf`

The report contains 31 pages and 40 numbered figures covering:

1. VPC peering architecture
2. VPC and subnet configuration
3. Internet gateway and route-table associations
4. Security group inbound and outbound rules
5. EC2 instance deployment and IP addressing
6. Bastion-host SSH access to private instances
7. VPC peering connection status and details
8. Forward and return route configuration
9. Connectivity tests, failure capture, and recovery
10. Viva preparation and core concepts
11. Resource inventory and implementation results
12. Cleanup and project closure

## Upload Notes

The report supplied for this project is a consolidated PDF with the screenshots embedded as figures. Individual screenshot files have not been added separately in the current upload.

If separate screenshots are added later, use numbered filenames that follow the report figure sequence, for example:

- `01_VPC_Peering_Architecture.png`
- `02_VPC_A_Configuration.png`
- `03_VPC_B_Configuration.png`

Keep the original evidence order and avoid including AWS account IDs in screenshots.
