# Day 1 – Cloud Computing Basics and AWS Pricing

**Class date:** 3 November 2026  
**Internship:** AWS & DevOps Internship

## Overview

The opening class introduced cloud computing, the three cloud service models, AWS service categories, and the fundamentals of AWS pricing.

## Topics Covered

### Cloud Computing

Cloud computing provides IT resources such as compute, storage, networking, and databases over the internet instead of requiring organizations to purchase and maintain all their own hardware.

### Cloud Service Models

| Model | What it provides | Example |
|---|---|---|
| IaaS | Servers, storage, and networking; users manage the operating system, applications, and data | Amazon EC2 |
| PaaS | A managed application platform so users can focus on application development | — |
| SaaS | Finished software accessed by users over the internet | Gmail |

### AWS Service Categories

- **Compute:** EC2, Lambda, Lightsail, Outposts
- **Storage:** S3, EBS, EFS
- **Databases:** RDS, Aurora, DynamoDB
- **Networking:** VPC, Elastic Load Balancer
- **Management and governance:** CloudWatch, CloudFormation
- **Security:** IAM

### AWS Pricing Fundamentals

The class covered three key pricing areas:

1. **Compute:** commonly charged by usage time, such as per hour or per second.
2. **Storage:** commonly charged per GB per month.
3. **Data transfer:** inbound data transfer to AWS was described in class as free, while outbound transfer to the internet or outside AWS is charged.

It also introduced purchasing options:

- **On-Demand:** start and stop resources as needed and pay for usage.
- **Reserved:** commit to a defined term in exchange for a discount.
- **Payment choices:** all upfront, partial upfront, or no upfront.

## Key Takeaways

- IaaS, PaaS, and SaaS describe different levels of cloud service management.
- AWS services are grouped by the capabilities they provide.
- Compute, storage, and data transfer are key components of AWS pricing.
- Understanding usage and purchasing options helps with cost planning.
