# Evidence – Mini Project 1

This folder contains the final project report and supporting implementation evidence.

## Evidence Report

**Expected report filename:** `Mini_Project_1_Report.pdf`

The consolidated report contains 31 pages and 40 numbered figures covering:

1. VPC peering architecture
2. VPC and subnet configuration
3. Internet gateway and route-table associations
4. Security group inbound and outbound rules
5. EC2 instance deployment and IP addressing
6. Bastion-host SSH access to private instances
7. VPC peering connection status and details
8. Forward and return route configuration
9. Connectivity tests, failure capture, and recovery
10. Viva preparation and core concepts
11. Resource inventory and implementation results
12. Cleanup and project closure

The report includes the screenshots as numbered figures. Keep any separately uploaded screenshots in the same evidence sequence.
