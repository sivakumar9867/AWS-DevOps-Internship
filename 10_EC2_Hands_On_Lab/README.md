# Day 10 – EC2 Hands-On Lab: Apache Web Server, EBS Volumes and Snapshots

**Internship:** AWS & DevOps Internship  
**Internship Day:** 10  
**Class date:** 12 November 2026

## Overview

This session focused on launching and configuring an Amazon EC2 instance, deploying an Apache web server through EC2 User Data, accessing the webpage over HTTP, and exploring EBS storage and snapshots.

## Topics Covered

- Launching and configuring an EC2 Linux instance
- AMIs, instance types, key pairs, networking and storage settings
- Public and private IPv4 addresses
- Installing and starting Apache (httpd) with EC2 User Data
- Configuring HTTP access through Security Group port 80
- Hosting and accessing a sample webpage
- Comparing EBS volumes with EC2 instance store
- Creating and attaching an additional EBS volume
- EBS snapshots and backup/recovery concepts
- Resource cleanup to avoid unnecessary charges

## Key Learning

This hands-on lab connected EC2 configuration, security group rules, launch-time automation, Apache deployment, persistent storage and snapshot-based backup into one AWS workflow.
