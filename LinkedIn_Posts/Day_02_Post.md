# AWS & DevOps Internship | Day 2 – EC2 Web Server Deployment & File Transfer

Continuing my AWS & DevOps Internship learning journey!

Today's hands-on task focused on deploying my first web server using Amazon EC2 and understanding how files can be transferred between local and remote systems.

**What I worked on:**
- Launched and configured an Amazon EC2 Linux instance.
- Installed and configured Apache HTTP Server.
- Set up Security Group inbound rules for HTTP and restricted SSH access.
- Deployed a custom webpage on Amazon Linux 2023.
- Verified the live webpage through the instance's public IP.
- Transferred files between my local machine and EC2 using WinSCP (SFTP).

**Key learning:** Gained practical experience with EC2 instance management, Linux commands, SSH connectivity, security groups, web server deployment, and file transfer.

Another step forward in building my cloud computing and DevOps skills through hands-on practice.
