# AWS & DevOps Internship | Mini Project 1 – AWS VPC Peering

As part of my AWS & DevOps Internship, I completed Mini Project 1, focused on establishing private connectivity between two Amazon VPCs using VPC Peering.

**Key implementation areas:**
- Created two VPCs with non-overlapping CIDR blocks
- Configured public and private subnets
- Deployed a public bastion host and two private EC2 instances
- Established and accepted a VPC Peering connection
- Configured route tables for communication between the VPCs
- Applied Security Group rules to control SSH and ICMP traffic
- Accessed private instances through the bastion host
- Verified connectivity in both directions and tested recovery after a connectivity interruption
- Completed resource cleanup after the lab

**Key learning:** This project helped me understand how VPC Peering, route tables, Security Groups, and bastion-host access work together to enable controlled private communication across separate VPC networks.

The project documentation and implementation evidence are maintained in my GitHub repository.
