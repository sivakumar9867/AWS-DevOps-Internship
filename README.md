## Session Notes

Day 1 covers cloud computing fundamentals, IaaS/PaaS/SaaS, AWS service categories, and AWS pricing basics.

Day 2 documents the EC2 practical, including instance setup, security rules, SSH access, file transfer, Apache, webpage deployment, and resource cleanup.

Day 3 covers AWS global infrastructure, including Regions, Availability Zones, and Edge Locations.

Day 7 covers IAM concepts, users, groups, policies, roles, and the principle of least privilege.

Day 8 covers the EC2 launch workflow, AMIs, instance types and families, pricing categories, key pairs, security groups, and instance states.

Day 9 covers IAM components, least privilege, MFA, the AWS Shared Responsibility Model, encryption and KMS, managed services, AWS service categories, and EC2 fundamentals.

Day 10 covers an EC2 hands-on lab, Apache deployment through User Data, HTTP access, EBS volumes, instance store, snapshots, and resource cleanup.

Mini Project 1 documents the design, implementation, verification, and cleanup of a VPC peering environment connecting two non-overlapping VPCs.
