# AWS & DevOps Internship | Day 7 (Class 4) – IAM: Identity and Access Management

Continuing my AWS & DevOps Internship learning journey.

Today's Class 4 session focused on AWS Identity and Access Management (IAM) and how access to AWS resources can be controlled.

**Key concepts covered:**
- Authentication, Authorization, and Accountability
- Root users and IAM users
- IAM Users, Groups, Policies, and Roles
- Policy versus Role
- Principle of Least Privilege
- Understanding Allow and Deny responses through an IAM permissions example

**Key takeaway:** Successfully signing in does not mean a user can access every AWS service. Permissions determine which actions are allowed, making least-privilege access an important security practice.
