# Mini Project 1 – AWS VPC Peering

**Internship:** AWS & DevOps Internship  
**Project:** Mini Project 1  
**AWS Region:** Asia Pacific (Mumbai) – `ap-south-1`

## Overview

This mini project demonstrates private IPv4 connectivity between two Amazon VPCs using VPC Peering. A public bastion host in VPC A provides SSH administration access to two private EC2 instances, while route tables and Security Groups control communication between the VPCs.
