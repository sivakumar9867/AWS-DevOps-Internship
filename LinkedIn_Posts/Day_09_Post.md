# AWS & DevOps Internship | Day 9 – IAM, MFA, Shared Responsibility Model & EC2 Basics

Continuing my AWS & DevOps Internship learning journey.

Today's session focused on strengthening my understanding of AWS security and core cloud concepts.

**Key topics covered:**
- IAM users, groups, policies and roles
- Principle of Least Privilege
- Multi-Factor Authentication (MFA)
- AWS Shared Responsibility Model
- Data Encryption, AWS KMS and Data Integrity
- Security OF the Cloud vs Security IN the Cloud
- Managed and Unmanaged Services
- AWS service categories
- Introduction to Amazon EC2 and IaaS

**Key learning:** Understanding the Shared Responsibility Model was one of the key takeaways from this session. AWS manages the security OF the cloud, while customers are responsible for security IN the cloud. I also learned how IAM, MFA and encryption help strengthen cloud security.

Looking forward to building on these fundamentals through practical AWS activities.
